# Общая база для нескольких устройств (Firebase)

Без этой настройки шахматка хранит брони только в браузере одного устройства.
С ней все устройства (компьютер, телефоны) видят одни и те же брони, изменения приходят сразу.
Firebase — сервис Google, для такого объёма бесплатный (тариф Spark).

## 1. Проект

1. Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
2. «Создать проект» → название, например `gost` → Google Analytics можно выключить → «Создать».

## 2. Вход по почте и паролю

1. Слева **Build → Authentication** → «Начать».
2. Вкладка **Sign-in method** → **Email/Password** → включить → «Сохранить».
3. Вкладка **Users** → **Add user** → почта и пароль, под которыми будете входить на всех 3 устройствах.
   (Можно завести и несколько пользователей — тогда добавьте их почты в правила ниже.)

## 3. База Firestore

1. Слева **Build → Firestore Database** → «Создать базу данных».
2. Регион — `eur3 (europe-west)` → режим **production** → «Создать».
3. Вкладка **Rules** → замените всё на правила ниже, впишите свою почту → **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email in ['ВАША_ПОЧТА@gmail.com'];
    }
  }
}
```

Правило пускает к данным только вошедших пользователей с перечисленными почтами,
поэтому ссылка на сайт в чужих руках ничего не даст.

## 4. Конфиг сайта

1. Шестерёнка вверху слева → **Project settings** → внизу «Your apps» → значок **</>** (Web).
2. Название любое, Firebase Hosting **не** включать → «Register app».
3. Скопируйте объект `firebaseConfig` и вставьте в файл `firebase-config.js` вместо `null`:

```js
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "....firebaseapp.com",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

Эти значения не секретные — доступ защищают вход и правила из шага 3.

4. В **Authentication → Settings → Authorized domains** добавьте `grach31.github.io`.

## Как это работает

- На каждом устройстве один раз входите по почте и паролю — вход запоминается.
- Вверху появляется метка: «Общая база ✓» — всё сохранено; «Сохраняется…»; «Нет сети — изменения отправятся позже».
- Без интернета шахматка открывается и редактируется, изменения уйдут при появлении сети.
- При первом входе, если в базе пусто, а на устройстве уже есть брони, сайт предложит их перенести.
- «Выйти» — в меню (на телефоне ☰).
- Если два человека в одну секунду поставят бронь на один номер, база примет обе — проверяйте шахматку.
