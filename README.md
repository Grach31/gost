# Гость — учёт номеров

Простое веб-приложение для учёта номеров небольшой гостиницы или базы отдыха.
Один файл `index.html`, без сервера и установки: открыл в браузере — работает.

## Возможности

- **30 номеров** трёх типов: двухместные, трёхместные, четырёхместные.
- **Статусы номера:** свободен / забронирован / заселён — цветом на карточке.
- **Карточка номера:** гость, телефон, число гостей, даты заезда и выезда, цена за ночь, оплата, заметка.
  Автоматически считаются ночи, итоговая сумма и остаток к оплате.
- **Подсказки:** «Пора выселять» (дата выезда прошла), «Не оплачено полностью».
- **Выселение** переносит проживание в **историю**.
- **Сводка:** свободно / забронировано / заселено, загрузка в %, долг по текущим гостям, получено по истории.
- **Поиск** по номеру, имени или телефону, фильтры по типу и статусу.
- **Настройки:** сколько номеров каждого типа (в сумме ровно 30) и цены за ночь.
- **Экспорт / импорт** всех данных в JSON — для резервной копии или переноса на другой компьютер.
- Закрытие окон по `Esc` или клику по фону.

## Как пользоваться

1. Скачайте `index.html` (или весь репозиторий) и откройте файл в браузере.
2. Нажмите **Настройки** и задайте количество номеров по типам и цены.
3. Кликните по номеру, чтобы забронировать или заселить гостя.

## Где хранятся данные

В `localStorage` браузера на этом компьютере. Данные не уходят в интернет,
но и не синхронизируются между устройствами — для переноса используйте **Экспорт / Импорт**.
Очистка данных браузера удалит записи, поэтому периодически делайте экспорт.

Общее число номеров задаётся константой `TOTAL_ROOMS` в начале скрипта в `index.html`.
