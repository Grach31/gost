# Гость — шахматка бронирования

Веб-приложение для небольшой гостиницы: шахматка номеров по дням месяца, как в привычной таблице Excel.
Один файл `index.html`, без сервера и установки: открыл в браузере — работает.

## Шахматка

- Строки — номера, сгруппированные по категориям (Эконом, Двухместный стандарт, Трехместный, Семейный, Люкс),
  с описанием кроватей: «двуспальная», «раздельные», «двуспальная +кресло».
- Столбцы — дни месяца с днями недели сверху и снизу, воскресенья подсвечены, сегодняшний день выделен.
- Листание месяцев кнопками ‹ › и «Сегодня».
- Брони — цветные полосы с именем гостя:
  оранжевая — бронь, зелёная — заселён, серая — выехал, красная метка слева — есть долг.
  Наведите курсор на полосу — увидите даты, сумму, долг и телефон.

## Как пользоваться

1. Откройте `index.html` в браузере.
2. **Новая бронь:** зажмите мышку на свободной клетке в строке номера и протяните до последней ночи,
   либо нажмите «+ Бронь».
3. Заполните гостя, телефон, даты, цену и оплату — ночи, итог и остаток к оплате считаются сами.
4. **Изменить или удалить:** кликните по полосе брони.
5. Пересекающиеся брони в одном номере приложение не даст сохранить.

## Настройки

- Категории номеров и цена за ночь для каждой.
- Список номеров: номер, категория, описание кроватей. Можно добавлять и удалять.
- «Сбросить всё» — вернуть номера по умолчанию и удалить все брони.

## Сводка за месяц

Загрузка в %, продано ночей, выручка за месяц, число заездов, сколько номеров занято сегодня, общий долг гостей.

## Данные

Хранятся в `localStorage` браузера на этом компьютере и никуда не отправляются.
Для резервной копии и переноса на другой компьютер — кнопки **Экспорт / Импорт** (файл JSON).
Очистка данных браузера удалит брони, поэтому периодически делайте экспорт.
Кнопка **Печать** печатает шахматку текущего месяца.
